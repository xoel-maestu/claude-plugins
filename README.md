# claude-plugins

Claude Code mods by Xoel García Maestu, published as the `xoel-plugins` marketplace.

| Plugin | What it shows |
| --- | --- |
| [context-meter](plugins/context-meter) | Context window fill at the bottom right of the prompt; detail card on hover and `/context-meter`. |

## Install

```
/plugin install context-meter --marketplace xoel-maestu/claude-plugins
```

## Credits

The `SessionMode` meter pattern is inspired by [midudev/better-claude](https://github.com/midudev/better-claude) (MIT). The code here is written from scratch.
